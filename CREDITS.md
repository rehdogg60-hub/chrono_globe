# Credits and Open-Source Notes

ChronoGlobe: Faith & History Explorer is published by Reh Dogg Games Plus.

It was built as a static browser game using:

- React
- React DOM
- Vite
- TypeScript
- Three.js
- Lucide React icons

The production build in `web/` includes bundled code from these open-source packages. Their respective licenses remain with their authors and maintainers.

No external API keys, paid map services, remote tile servers, or third-party runtime accounts are required for the packaged web build.

Primary game content is stored in the source project under `src/data/events.ts` and is compiled into the static web release.
